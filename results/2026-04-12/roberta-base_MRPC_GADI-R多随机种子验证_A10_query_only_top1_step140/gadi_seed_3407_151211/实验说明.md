# 实验说明

## 一、实验目的

本实验用于验证固定配置 `step140 + gradient_mix=0.5 + query_only` 的 GADI-R 在不同随机种子下是否稳定，并观察它相对当前 LoRA / LoRA-GA 参考基线是否仍有优势。

## 二、实验配置

- 实验方法：GADI-R
- 随机种子：3407
- 模型：roberta-base
- 数据集：glue/mrpc
- LoRA Rank：8
- LoRA Alpha：16
- 训练轮数：1
- 训练批大小：16
- 重基化步数：140
- 选择策略：query_only
- topk_layers：1
- gradient_mix：0.5
- 校准 batch 数：8

## 三、实验结果

- 最终验证集 Loss：0.448371
- 最终验证集 Accuracy：0.764706
- 训练过程最好验证集 Loss：0.476252
- 训练过程最好验证集 Accuracy：0.750000
- 最好结果出现步数：200
- 相对 LoRA 参考基线 Accuracy 差值：-0.017157
- 相对 LoRA-GA 参考基线 Accuracy 差值：-0.046569
- 总耗时（秒）：20.65
