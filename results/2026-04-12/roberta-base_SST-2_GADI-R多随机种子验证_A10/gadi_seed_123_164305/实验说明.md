# 实验说明

## 一、实验目的

本实验用于验证固定配置 `step120 + gradient_mix=0.5 + query_only + topk_layers=1` 的 GADI-R 在 `SST2` 任务上的表现是否稳定，并观察其相对 LoRA / LoRA-GA 是否仍有优势。

## 二、实验配置

- 方法：`GADI-R`
- 随机种子：`123`
- 模型：`roberta-base`
- 数据集：`glue/sst2`
- LoRA Rank：`8`
- LoRA Alpha：`16`
- 训练轮数：`1`
- 训练 batch size：`16`
- 重基化步数：`120`
- 选择策略：`query_only`
- topk_layers：`1`
- gradient_mix：`0.5`
- 校准 batch 数：`8`
