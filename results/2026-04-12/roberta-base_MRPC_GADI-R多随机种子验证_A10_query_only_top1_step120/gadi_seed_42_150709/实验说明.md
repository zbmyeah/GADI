# 实验说明

## 一、实验目的

本实验用于验证固定配置 `step120 + gradient_mix=0.5 + query_only` 的 GADI-R 在不同随机种子下是否稳定，并观察它相对当前 LoRA / LoRA-GA 参考基线是否仍有优势。

## 二、实验配置

- 实验方法：GADI-R
- 随机种子：42
- 模型：roberta-base
- 数据集：glue/mrpc
- LoRA Rank：8
- LoRA Alpha：16
- 训练轮数：1
- 训练批大小：16
- 重基化步数：120
- 选择策略：query_only
- topk_layers：1
- gradient_mix：0.5
- 校准 batch 数：8

## 三、实验结果

- 最终验证集 Loss：0.365337
- 最终验证集 Accuracy：0.830882
- 训练过程最好验证集 Loss：0.414324
- 训练过程最好验证集 Accuracy：0.791667
- 最好结果出现步数：200
- 相对 LoRA 参考基线 Accuracy 差值：+0.049020
- 相对 LoRA-GA 参考基线 Accuracy 差值：+0.019608
- 总耗时（秒）：60.31
